# Tasks & Scoring Rubric — Piloto (2–4 semanas)

Objetivo: validar PoC de receipts → Merkle → claim; testar score/reward e pension lock; validar políticas.

Tarefas por perfil (exemplos curtos)

A. Desenvolvedor (Blockchain / Tokenomics)
- Tarefa: implementar contrato de claim stub (ERC‑20 minimal) ou escrever pseudo‑código de claim flow.
- Entregável: PR ou documento com API e exemplo de uso.

B. Mobile / Edge Engineer
- Tarefa: rodar scripts/poc/receipt_tool.py; gerar receipts; enviar receipts para merkle_aggregator; criar batch.
- Entregável: receipts + batch JSON + breve log de execução.

C. Privacidade / Compliance
- Tarefa: revisar docs/consent_partner_policy.md e sugerir 3 mudanças para robustez legal.
- Entregável: comentário no documento ou PR.

D. Hardware / Partners
- Tarefa: descrever fluxo de voucher redemption (contrato parceiro, logística, validação Gate Hub).
- Entregável: diagrama curto e lista de requisitos.

Scoring (0–100)
- Técnica (0–40): completude e qualidade técnica do entregável.
- Compliance/Ética (0–30): aderência às políticas de consentimento e privacidade.
- Fit / Colaboração (0–30): comunicação, prontidão, disponibilidade e ética.

Critério de aprovação: score >= 70. Para convidados iniciais, prioridade para scores >=80.

Recompensa/Compensação
- Pequeno bounty em créditos Gaia (voucher) por entrega aprovada; detalhar valor no convite.
- Para participantes chave, convite para continuar no time piloto com remuneração combinada.
