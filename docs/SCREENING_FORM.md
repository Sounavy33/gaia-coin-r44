# Screening Form — perguntas sugeridas (formulário curto)

Instruções: colocar como Google Form ou Typeform. Mantenha consentimento e clareza.

1) Nome completo
2) Apelido / como prefere ser chamado
3) E‑mail
4) GitHub (link)
5) LinkedIn (link)
6) Perfil (selecione): Blockchain / Mobile/Hardware / Privacidade / IA / ONG / Produto / Outro
7) Experiência (breve): descreva em 2–4 linhas sua experiência relevante
8) Interesse: por que quer colaborar com a Gaia Coin? (resposta curta)
9) Disponibilidade estimada (horas/semana) e duração possível
10) Consentimento (checkbox): concordo em participar do piloto, compartilhar resultados técnicos para fins de pesquisa e aceitar termos de triagem (NDA opcional). Assinar com nome.
11) Upload (opcional): pequeno CV / link para portfólio / prova (PDF)

Tarefas iniciais indicativas (escolha até 2 preferidas):
- Rodar PoC de receipts (scripts/poc) e enviar 3 receipts gerados
- Revisar Consent Policy e enviar 3 melhorias propostas
- Desenhar fluxo de voucher para hardware (1 página)
- Revisar checklist anti‑fraude e propor 2 melhorias

Observação: após triagem, enviaremos tarefas técnicas e instruções para o teste/aval.
